# GUI Testing Exercise — Playwright

Bài thực hành kiểm thử GUI trang Login của SauceDemo bằng Playwright.

- Thời gian: 30 phút
- Hình thức: Làm theo cặp
- Website: https://www.saucedemo.com/

---

### Bước 1

Trên repository GitHub, chọn:

**Code → Codespaces → Create codespace on main**

Chờ môi trường được chuẩn bị tự động.

> Khi Codespace được tạo, dependency của project sẽ được cài tự động.
> Không cần tự cài Node.js, Playwright hoặc Chromium.

### Bước 2

Đọc đề bài:

`docs/DE-BAI.md`

### Bước 3

Mở file:

`tests/login-gui.spec.ts`

Hoàn thành các vị trí `TODO`.

Nếu quên cú pháp Playwright, xem:

`docs/CHEAT-SHEET.md`

### Bước 4

Mở Terminal và chạy:

```bash
npm test
```
Để thực thi test.

```bash
npm run report
```
Để xem báo cáo trực quan của test chạy gần nhất.
